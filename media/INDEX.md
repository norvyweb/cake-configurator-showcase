# Media index

Version 2, captured on 25 November 2026 from Cake Composer 0.8.7 running on a local test
installation, with invented test data.

Every image is a real capture of the product. Nothing is mocked up, retouched or generated.
The interface shows **Pasteluxe**, the demo theme of the product. Prices in the images are test
values, not a client's prices. No order was placed while capturing. Image metadata has been
removed.

[Contact sheet](contact-sheet.png): every gallery image and screenshot on one page.

including the custom-colour option, finishes, separators and approved decorations) and captured

for these captures; the cake, the scene and the lighting are unchanged.
