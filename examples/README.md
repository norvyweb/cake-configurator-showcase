# Engineering samples

Five small samples written from scratch for this repository. None of them is code from Cake
Composer. Each folder's README covers the problem, the approach, usage, tests and limits.

| Sample | Tests | Measurement |
| --- | --- | --- |
| [webgl-shader-cache](webgl-shader-cache/) | `npm test` | `npm run bench` (headless Chromium) |
| [glb-runtime-safety](glb-runtime-safety/) | `npm test` | `npm run measure` |
| [device-quality-tiers](device-quality-tiers/) | `npm test` | `npm run measure` |
| [undo-redo-store](undo-redo-store/) | `npm test` | none |
| [rtl-kiosk-kit](rtl-kiosk-kit/) | `npm test` | demo page |

Requirements: Node.js 18.17 or later. Run `npm install` once at the repository root.
